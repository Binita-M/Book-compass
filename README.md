Book Compass is a Python-based book recommendation system that uses collaborative filtering and matrix completion to predict how users might rate books they have not yet read. The system organizes ratings into a user-book matrix, applies mean-centering to account for differences in book ratings and uses iterative SVD reconstruction to estimate missing ratings while keeping known ratings unchanged. It uses a validation set and RMSE to select the best rank. The completed matrix is then used to predict ratings on the original 1-5 scale, and the system recommends the top-rated books for each user
